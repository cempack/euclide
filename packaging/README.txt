Euclide, le bureau d'enseignement
=================================

La version portable pour Windows : rien à installer.


Lancer Euclide
--------------

Double-cliquez sur euclide.exe.

La première fois, Windows peut afficher « Windows a protégé votre
ordinateur » : cliquez sur « Informations complémentaires », puis sur
« Exécuter quand même ».


Sur une clé USB
---------------

Copiez tout ce dossier sur la clé, puis lancez euclide.exe depuis la clé.
Euclide et ses données passent ainsi d'un ordinateur à l'autre.


Ce que contient le dossier
--------------------------

euclide.exe         le programme.
euclide-sidecar     ce qui fait marcher Python et Pronote. À garder à côté
                    d'euclide.exe.
euclide.portable    dit à Euclide qu'il est la version portable.
Euclide-Data        les cours, les documents et les notes. Il apparaît au
                    premier lancement.

Ne supprimez rien de tout cela.


Les données
-----------

Tout est dans Euclide-Data, à côté d'euclide.exe. Chaque jour, Euclide en
fait une copie dans Euclide-Sauvegardes, juste à côté. Pour en garder une
autre ailleurs, sur le PC ou dans un dossier synchronisé : Réglages,
Sauvegardes.


Les mises à jour
----------------

Euclide se met à jour tout seul : il enregistre le travail ouvert,
remplace ses propres fichiers dans ce dossier, puis redémarre.
Euclide-Data n'est jamais touché.


Plus d'informations : https://euclide.elliotmoreau.fr
